# FLOWSHIELD UI

`dashboard_ui.py` mirrors the root Streamlit dashboard (`app.py`).

## India study areas

Chennai, Mumbai, Delhi, Kolkata, Guwahati, Hyderabad, Bengaluru, Patna, Kochi, Surat, Visakhapatnam, Bhubaneswar, Srinagar, Alappuzha, Vadodara, Mangaluru.

## Run

```bash
py -3 -m pip install -r requirements.txt
py -3 -m streamlit run app.py
```

Map: Google Earth satellite + grid lines + district/city name pointers.
